## 🚀 **النظرة العامة**

**MECO Wallet** ليست مجرد محفظة رقمية... بل هي **بوابتك الكاملة إلى الاقتصاد الرقمي اللامركزي**!

في عالمٍ تزدحم فيه المحافظ الرقمية، نطرح سؤالاً جوهرياً: **ما الذي يجعل MECO مختلفة؟**

✨ **الإجابة تكمن في رؤيتنا:**
- 🎯 نحن لا نكتفي بتخزين العملات؛ بل نصنع **مركز تحكم شخصي** يمنحك الحرية الكاملة
- 💪 إدارة كاملة لأموالك بدون وسيط
- 🔐 أمان عالي المستوى مع تشفير قوي
- 🌍 تطبيق لامركزي حقيقي يعمل بدون خوادم وسيطة

**MECO Wallet انطلقت بقوة وتعمل اليوم بكفاءة عالية لتثبت أنها أكثر من مجرد أداة إرسال واستقبال.**

## 🧱 **التقنيات المستخدمة (Tech Stack)**

### 📲 **الإطار والمكتبات الأساسية**
- **React Native & Expo** (SDK 54) - لبناء تطبيق متعدد المنصات
- **TypeScript** - لتطوير آمن وخالٍ من الأخطاء

### ⛓️ **تكامل البلوكتشين**
- **Solana Web3.js** - للتفاعل مع شبكة Solana
- **SPL-Token** - معيار الرموز على شبكة Solana
- **@solana/transactions** - بناء وتوقيع المعاملات

### 🔐 **الأمان والتخزين**
- **expo-secure-store** - تخزين المفاتيح الخاصة بشكل آمن
- **AsyncStorage** - تخزين البيانات المحلية
- **TweetNaCl.js** - تشفير وتوقيع البيانات

### 🌐 **الاتصالات واللامركزية**
- **WalletConnect v2 Core** - ربط آمن مع تطبيقات Web3
- **Helius RPC** - اتصالات سريعة وموثوقة مع شبكة Solana
- **Ankr RPC** - خادم بديل احتياطي للاتصالات

### 💱 **الأسعار والتبادل**
- **Jupiter API** - مزود السيولة الأمثل للتبادلات
- **CoinGecko API** - أسعار حقيقية ومحدّثة للعملات

### 🌍 **تعدد اللغات والترجمة**
- **i18next** و **react-i18next** - دعم العربية والإنجليزية ولغات أخرى

### 📊 **الواجهة والمكتبات الإضافية**
- **React Navigation** - ملاحة سلسة بين الشاشات
- **Redux/Context API** - إدارة الحالة المركزية
- **React Query** - إدارة الاستعلامات والبيانات

## 🔐 **الأمان والخصوصية (Security)**

### 🛡️ **معايير الأمان العالية**

✅ **المفاتيح الخاصة (Private Keys)**
- مشفرة ومخزنة محلياً باستخدام `expo-secure-store`
- **لا تغادر جهاز المستخدم أبداً**؛ فقط أنت تملك مفاتيحك
- لا توجد نسخة احتياطية على خوادم بعيدة

✅ **المصادقة (Authentication)**
- دعم المصادقة البيومترية (بصمة الإصبع / Face ID)
- حماية إضافية لعبارة الاسترداد (Seed Phrase)
- رمز PIN اختياري إضافي

✅ **اللامركزية الحقيقية**
- **لا توجد خوادم وسيطة** تمتلك صلاحية الوصول لأموالك
- تحكم كامل وحصري في محفظتك
- لا تعتمد على جهات خارجية لتخزين الأموال

✅ **الشفافية والثقة**
- كود **مفتوح المصدر** على GitHub
- يمكن لأي شخص مراجعة الكود والتحقق من الأمان

### ⚠️ **نصائح الأمان للمستخدمين**

1. **احفظ كلمات الاسترداد** في مكان آمن وبعيد عن الإنترنت
2. **لا تشارك مفاتيحك الخاصة** مع أي شخص أو موقع
3. **فعّل المصادقة البيومترية** لحماية إضافية
4. **حدّث التطبيق** بانتظام للحصول على أحدث تحديثات الأمان

## 📥 **المتطلبات والتثبيت**

### ✅ **متطلبات التشغيل**

**للمستخدمين النهائيين:**
- 📱 هاتف ذكي بنظام **Android 8.0** أو أحدث
- 💾 مساحة تخزين: **100 MB** على الأقل
- 🌐 اتصال إنترنت مستقر

**للمطورين:**
- 💻 Node.js v18+ و npm أو yarn
- 🔧 Expo CLI مثبت عالمياً
- 🎯 Android Studio (اختياري)
- 📝 محرر نصوص مثل VS Code

### 🚀 **خطوات التثبيت للمطورين**

```bash
git clone https://github.com/MonyCoin/meco_wallet.git
cd meco_wallet
npm install
# أو yarn install
npm install -g expo-cli
expo start
```

لإنشاء ملف APK للإنتاج:

```bash
eas build --platform android --build-profile production
```

### 📋 **متغيرات البيئة (.env)**

أنشئ ملف `.env` في جذر المشروع:

```env
SOLANA_RPC_URL=https://api.mainnet-beta.solana.com
HELIUS_API_KEY=your_helius_key_here
ANKR_API_KEY=your_ankr_key_here
JUPITER_API_KEY=your_jupiter_key
WALLETCONNECT_PROJECT_ID=your_walletconnect_project_id
COINGECKO_API_KEY=your_coingecko_key
```

## 💡 **دليل الاستخدام**

### 🆕 **إنشاء محفظة جديدة**
1. افتح التطبيق واختر **"إنشاء محفظة جديدة"**
2. اقرأ التحذيرات الأمنية واضغط **متابعة**
3. احفظ **12 كلمة استرجاع** في مكان آمن
4. أكد كلمات الاسترجاع وحدد كلمة مرور قوية

### 📤 **إرسال عملات**
1. اضغط **"إرسال"** من الشاشة الرئيسية
2. أدخل العنوان أو امسح رمز QR
3. أدخل المبلغ وراجع الرسوم والتفاصيل
4. اضغط **تأكيد وإرسال** وأكمل المصادقة عند الطلب

### 📥 **استقبال عملات**
1. اضغط **"استقبال"**
2. شارك عنوان المحفظة أو رمز QR مع المرسل
3. راقب وصول العملية من خلال إشعارات الاستقبال وسجل العمليات

### 🔄 **تبديل العملات (Swap)**
1. اضغط **"تبديل"**
2. اختر عملة الإرسال والاستقبال
3. أدخل المبلغ وراجع السعر المرجعي
4. اضغط **تأكيد التبديل** وأكمل المصادقة

### ⚡ **تخزين العملات (Staking)**
1. اذهب إلى قسم **"التخزين"**
2. اختر المبلغ ومدة التخزين
3. تابع العوائد اليومية؛ ويمكن السحب في أي وقت للخطط المرنة
