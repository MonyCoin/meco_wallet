## 🚀 المميزات الرئيسية

### 🔐 الأمان والملكية

- إنشاء محفظة جديدة أو استيراد محفظة موجودة.
- تخزين المفاتيح الخاصة محلياً باستخدام `expo-secure-store`.
- دعم المصادقة البيومترية و`PIN` الاختياري.
- بيئة لا مركزية **Non-custodial**؛ المستخدم هو المالك الوحيد لمحفظته.
- **النمط الداكن (Dark Mode) هو النمط الأساسي والوحيد للتطبيق**، بتصميم مسطح موحّد في كل الشاشات.

### 💸 إدارة الأصول

- إرسال واستقبال MECO وجميع رموز SPL المدعومة على Solana.
- **دعم 15 عملة رقمية قابلة للتداول والمبادلة** على شبكة Solana.
- إدارة حسابات متعددة، لكل حساب رصيده وبياناته الخاصة.
- إضافة الرموز المخصصة من خلال عنوان العقد الذكي.
- **سجل عمليات تفاعلي** داخل شاشة المحفظة لتحليل العمليات الواردة والصادرة.

### 🖥️ شاشة المحفظة المُحسّنة

- **قسم التداول السريع (Quick Trade):** تنفيذ عمليات التبادل مباشرة من الشاشة الرئيسية دون التنقل بين شاشات متعددة.
- **قسم ملخص السيولة:** حصتك في مجمعات MECO وقيمتها ورسومها المتراكمة، أو بطاقة تعريفية إن لم تكن لديك حصة.
- **قسم سجل العمليات (Activity Log):** متابعة كاملة لكل العمليات الواردة والصادرة والتبديلات من مكان واحد.

### 🔄 التداول وWeb3

- مبادلة فورية عبر **Jupiter** وبأسعار تنافسية.
- شاشة سوق معاد تصميمها: بانر حي لسعر **MECO**، نظرة عامة على الأسواق، قائمة عملات مسطحة مع "عرض المزيد"، وبطاقات أزواج الفوركس. الأسعار عبر **CoinGecko** و**Jupiter**.
- شاشة تداول احترافية لمتابعة السوق.
- دعم **WalletConnect v2** للاتصال بتطبيقات Web3 وDeFi، مع نافذة توقيع داكنة وطابور للطلبات المتعددة.
- **حماية التوقيع:** يُرفض أي طلب توقيع تخص جلسته حساباً غير الحساب النشط، فلا يُوقَّع بحساب خطأ أبداً.
- **التحقق من النتيجة على الشبكة:** لا يُبلَّغ الموقع بنجاح كاذب إذا فشلت المعاملة فعلياً.
- متصفح Web3 مدمج للتفاعل مع التطبيقات اللامركزية.
- شاشة **استكشاف (Explore)** جديدة: بحث، بانرات، مفضلة وتبويبات اكتشاف.

### 💧 السيولة (Orca)

- شاشة **السيولة** مبنية على مجمعَي MECO على Orca: **MECO/SOL** و**MECO/USDT**، وسيولة المشروع فيهما **مقفلة نهائياً** ويمكن التحقق منها على السلسلة.
- إحصاءات حية لكل مجمع: الحجم، التداول، رسوم المجمع والعائد التقريبي من رسوم المتداولين الفعلية.
- **مراكزي:** قيمة حصتك ورسومك المتراكمة، مع **سحب كامل** و**جمع الرسوم** مباشرة من التطبيق.
- **الإيداع عبر موقع Orca الرسمي** بربط المحفظة بـ WalletConnect (والمركز يبقى ملكك)، بلا رسوم خدمة على الإيداع.
- رسوم خدمة التطبيق **0.0005 SOL على السحب فقط**، تُحصَّل بمعاملة منفصلة بعد نجاح السحب، في محفظة معلنة.
- المراكز المقفلة تُعرض بعلامة "مقفل" دون زر سحب.
- العائد يأتي من رسوم التداول الفعلية فقط، ولا يضمنه المشروع، وقد تتغير قيمة الحصة مع حركة السعر.

### 📒 التنظيم والتنبيهات

- إشعارات محلية ذكية مع Badge وسجل للعمليات.
- اكتشاف تلقائي للأموال الواردة عند فتح التطبيق.
- تنبيهات سعرية عند وصول أي عملة إلى السعر المستهدف صعوداً أو هبوطاً.
- دفتر عناوين متقدم مع:
  - تصنيفات ملوّنة: عائلة، عمل، أصدقاء، منصات، أخرى.
  - بحث فوري وترتيب بالأحدث أو الأبجدي أو الأكثر استخداماً.
  - ملاحظات وإحصائيات استخدام لكل عنوان.
  - حفظ وتعديل وحذف العناوين مباشرة من شاشة الإرسال.
- ماسح QR ذكي مع عودة مباشرة إلى شاشة الإرسال.
- دعم العربية والإنجليزية.

## 🛠️ التثبيت للمطورين

### المتطلبات

- Node.js `v18+`
- npm أو Yarn
- Expo CLI
- Android Studio للاختبار المتقدم، عند الحاجة

### التشغيل محلياً

```bash
git clone https://github.com/MonyCoin/meco_wallet.git
cd meco_wallet
npm install
npm install -g expo-cli
expo start
```

لبناء نسخة Android للإنتاج:

```bash
eas build --platform android --build-profile production
```

### متغيرات البيئة

المفاتيح السرية تُقرأ من متغيرات البيئة ولا تُكتب داخل الكود. أنشئ ملف `.env` في جذر المشروع ولا ترفعه إلى GitHub:

```env
EXPO_PUBLIC_HELIUS_API_KEY=your_helius_key_here
EXPO_PUBLIC_ALCHEMY_API_KEY=your_alchemy_key_here
EXPO_PUBLIC_FINNHUB_API_KEY=your_finnhub_key_here
```

| المتغير | الاستخدام |
|:---|:---|
| `EXPO_PUBLIC_HELIUS_API_KEY` | مزود RPC الأساسي (`heliusService.js`) |
| `EXPO_PUBLIC_ALCHEMY_API_KEY` | مزود RPC الاحتياطي (`alchemyService.js`) |
| `EXPO_PUBLIC_FINNHUB_API_KEY` | أسعار الأسهم والأخبار (`marketDataService.js` و`assetChartService.js`) |

عند التشغيل المحلي تُقرأ المتغيرات من ملف `.env`. أما في تحديثات الإنتاج فتُضاف إلى بيئة `production` في Expo (EAS Environment Variables)، ثم تُحقن وقت البناء أو تنفيذ `eas update`. يجب كتابة `process.env.EXPO_PUBLIC_*` بصيغتها المباشرة في الكود ليعمل الاستبدال الثابت.

> **تنبيه:** متغيرات `EXPO_PUBLIC_*` تُدمج داخل حزمة التطبيق عند البناء، فهي تُخفي المفاتيح عن المستودع لكنها لا تجعلها سرية تمامًا. استخدم مفاتيح بصلاحيات وحصص محدودة، وبدّلها فورًا عند الاشتباه بتسريبها.

### 🔁 الخدمة الاحتياطية لمزود RPC

- **الأساسي:** `services/heliusService.js` يتعامل مع Helius فقط.
- **الاحتياطي:** `services/alchemyService.js` نسخة موازية من خدمة Helius بنفس الدوال والمنطق والأسماء، وتعمل عبر Alchemy مع نقاط RPC عامة كخيار أخير.
- **التحويل التلقائي:** عند تعطل Helius (انتهاء الحصة أو انقطاع الخدمة أو غياب المفتاح) تُحوَّل كل الدوال تلقائيًا إلى `alchemyService`، ويُعاد فحص Helius دوريًا فيعود التطبيق إليه تلقائيًا بمجرد عودته. لا يلزم تعديل أي شاشة أو خدمة أخرى لأن كل الاستدعاءات تمر عبر `heliusService`.
- **تأكيد المعاملات:** المكتبة الافتراضية تؤكد المعاملة عبر WebSocket (`signatureSubscribe`)، وبعض المزودين مثل Alchemy لا يدعمها، فتنتهي المعاملة على الشبكة بنجاح بينما يعرض التطبيق فشلًا كاذبًا. لذلك تؤكد `alchemyService` المعاملات بالاستعلام الدوري عن حالة التوقيع عبر HTTP (`getSignatureStatuses`) مع فحص انتهاء صلاحية الـ blockhash، فتظهر النتيجة الصحيحة دون الاعتماد على WebSocket.

## 🔒 الأمان والخصوصية

- المفاتيح الخاصة **لا تغادر جهاز المستخدم**.
- لا توجد نسخة احتياطية للمفاتيح على خوادم بعيدة.
- لا توجد خوادم وسيطة تمتلك صلاحية الوصول إلى أموالك.
- استخدم عبارة استرداد قوية واحفظها خارج الإنترنت.
- لا تشارك عبارة الاسترداد أو المفتاح الخاص مع أي شخص.
- فعّل المصادقة البيومترية وحدّث التطبيق باستمرار.
- مفاتيح الخدمات (Helius وAlchemy وFinnhub) تُقرأ من متغيرات البيئة ولا تُكتب في الكود المصدري.
- عند تعطل مزود RPC الأساسي يتحول التطبيق تلقائيًا إلى مزود احتياطي دون انقطاع الخدمة.

> **تنبيه:** أنت المسؤول عن حفظ عبارة الاسترداد والمفاتيح الخاصة. لا يستطيع فريق MECO استعادتها إذا فُقدت.

## 📖 دليل الاستخدام السريع

### إنشاء محفظة

1. اختر **إنشاء محفظة جديدة**.
2. احفظ كلمات الاسترداد الاثنتي عشرة في مكان آمن.
3. أكد الكلمات وحدد كلمة مرور قوية.

### إرسال واستقبال

1. اختر **إرسال** أو **استقبال** من الشاشة الرئيسية.
2. أدخل العنوان أو استخدم ماسح QR.
3. راجع المبلغ والرسوم قبل تأكيد العملية.
4. استخدم دفتر العناوين لحفظ العناوين المتكررة وتنظيمها.

### التداول السريع من شاشة المحفظة

1. افتح **قسم التداول السريع** في شاشة المحفظة.
2. اختر العملة والمبلغ مباشرة.
3. راجع السعر المتوقع وأكّد العملية.

### Swap

1. اختر العملة والمبلغ من قسم **Swap**.
2. راجع السعر المتوقع.
3. أكد العملية وأكمل المصادقة عند الطلب.

### السيولة

1. افتح **السيولة** من الإعدادات أو من شاشة المحفظة، واختر المجمع (MECO/SOL أو MECO/USDT).
2. **للإيداع:** اضغط **إيداع عبر Orca**، ثم في الموقع اضغط Connect Wallet واختر WalletConnect، والتقط لقطة شاشة لرمز QR واقرأها من ماسح التطبيق (أيقونة المعرض)، ثم Create Position ووقّع. قد يتطلب Orca استخدام VPN في بعض المناطق.
3. **للسحب أو جمع الرسوم:** من بطاقة **مراكزي** اضغط **سحب كامل** أو **جمع الرسوم**. رسوم الخدمة 0.0005 SOL على السحب فقط.

> العائد من رسوم التداول الفعلية فقط وليس مضموناً، وقد تقل قيمة حصتك عن الاحتفاظ بالعملتين إذا تحرك السعر.
